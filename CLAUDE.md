# Разборы боёв: правила для Claude

Репозиторий для шортсов-разборов боёв (9:16, 720×1280). Формат описан в `FORMAT.md`, референсы в `FORMAT_NOTES.md`. Перед работой над разбором прочитать `FORMAT.md`.

## Жёсткие правила

1. **Ничего не озвучивать и не рендерить целиком, пока пользователь не пришлёт сырой фрагмент и не напишет «делай».** Планы и проверки (`voice.mjs --plan`, пробные рендеры 2–3 с для отладки) можно.
2. Ключи ElevenLabs только из переменных окружения, не печатать и не записывать в файлы.
3. Исходные видео (`clips/`), `work/`, `out/` в git не кладём.
4. Не писать «исправил» или «готово», пока результат не проверен по кадрам (правило 4 ниже). В отчёте указывать, что проверено и что нет.

## Как делать разбор

Стрелки, рамки, отметки ставит Claude, пользователь даёт только сырой фрагмент и, если хочет, тезис.

1. **Кадры.** Для каждого удара: `node tools/frames.mjs clip.mp4 --from A --to B --every 0.1 --out work/frames --grid 4`. Кадры каждые 0,1–0,2 с, в полном размере (для мелких деталей `--crop x:y:w:h`). Смотреть сами PNG, не только контактный лист.
2. **Контакт.** Найти кадр контакта (первый кадр, где перчатка касается цели). Записать в `episodes/<имя>/plan.md`: время в исходнике, координаты кулака в замахе и в контакте, координаты цели.
3. **Разметка.** Время исходника перевести в время замедленного клипа (`tools/timemap.mjs`). В `annotations.json`: стрелка с `track` по ключам кулака (остриё на кулаке, в контакте на цели), рамка на цели, отметка `star` в кадре контакта. Правила в `docs/ANNOTATIONS.md`.
4. **Проверка по кадрам.** Рендер `annotate`, затем `node tools/verify.mjs clip.mp4 annotated.mp4 annotations.json`. Он проверяет только, что нарисованное стоит там, где написано в json. Что оно стоит на ударе, проверять глазами: открыть кадры вокруг контакта (`frames.mjs` на готовом клипе, `--every 0.1`), посмотреть положение острия относительно кулака и цели. Если не совпало: исправить `annotations.json`, перерисовать, снова посмотреть кадры. Записать в `plan.md`, какие кадры смотрели и что нашли.
5. Только после этого писать «исправлено»: с указанием кадров, по которым это видно.

## Конвейер

```
cut → slowmo → annotate → vertical → subs → (озвучка: voice → words.json → subs; звук склеить отдельно)
```

- `tools/cut.mjs`, `slowmo.mjs` (+ `timemap.mjs`), `annotate.mjs`, `vertical.mjs`, `subs.mjs`, `voice.mjs`, `frames.mjs`, `verify.mjs`, `build-short.mjs` (весь конвейер по `episodes/<имя>/timeline.json`).
- `npm run selftest` проверяет инструменты на синтетическом клипе и поддельном сервере ElevenLabs (реальный API не трогает).
- Рендер Remotion в этом облаке: предустановленный Chromium (`/opt/pw-browsers/chromium`), `--gl=angle`, у бинарников compositor `chmod +x` (делает `tools/lib/common.mjs`).

## Новый выпуск

1. Сначала прочитай `WORKFLOW.md` и `LESSONS.md`.
2. Потом спроси пользователя, какой клип и что разбирать (боец, момент, тезис), и не начинай поиск момента, пока не получишь ответ.
3. Дальше иди по шагам `WORKFLOW.md`; озвучка и полный рендер только после «да».
